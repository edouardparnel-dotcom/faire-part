QR code pour l'entrée de votre mariage

Dans les grands mariages, il y a toujours des personnes qui n'étaient pas invitées, et une liste papier impossible à tenir à l'entrée.

Chaque invité reçoit son pass avec un QR code sur sa page d'invitation. Le jour J, vous ou un proche le scannez avec votre téléphone : l'écran affiche son nom, le nombre d'accompagnants et les cérémonies auxquelles il est convié. S'il est déjà entré, vous le voyez aussi.

L'espace

À l'entrée

Un pass par invité

Sur sa page d'invitation, dans son téléphone.

Scanné avec un téléphone

Celui de l'organisateur ou d'un proche connecté à l'espace ; sans caméra, on tape le code.

Les bonnes informations

Nom, accompagnants, cérémonies où il est attendu, régime alimentaire.

Pas de double entrée

Un pass déjà utilisé s'affiche avec l'heure de son passage.

Questions

Ce qu'on nous demande

Faut-il un appareil spécial pour scanner ?

Non : un téléphone avec un appareil photo suffit.

Que se passe-t-il si un invité a oublié son téléphone ?

Vous saisissez son code à la main, ou vous vérifiez son nom dans votre liste d'invités, depuis votre espace.

Le contrôle d'entrée est-il inclus ?

Oui dans la formule Prestige, ou en option à 50 €.

Que paie-t-on, et quand ?

Rien pour préparer : vous ne payez qu'au moment d'envoyer le lien à vos invités. Les formules vont de 125 à 495 €, avec une remise de lancement pour les 50 premiers couples.

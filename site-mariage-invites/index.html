Questions

Ce qu'on nous demande

Le site est-il inclus ?

Oui, dans les formules Signature (199 €) et Prestige (495 €).

Le site est-il public ?

Il s'ouvre depuis le lien de chaque invité. Avec l'option « Accès par code », rien ne s'ouvre sans le code que vous donnez.

Combien de temps reste-t-il en ligne ?

Douze mois après la date du mariage, puis une année de plus si vous le souhaitez (29 €).

Que paie-t-on, et quand ?

Rien pour préparer : vous ne payez qu'au moment d'envoyer le lien à vos invités. Les formules vont de 125 à 495 €, avec une remise de lancement pour les 50 premiers couples.
